Episode Production

Privacy policy

Effective September 23, 2026

Episode Production is a personal video-production workflow operated by Joel Bertin for his own account. This policy describes its current use of Google Drive and related services.

Google Drive access

The desktop workflow uses Google OAuth to obtain permission to upload, inspect and delete files. The requested Drive permission is broader than one folder. The workflow is configured to use a designated private review folder; this configuration is not a Google-enforced folder-only permission.

The workflow uploads selected review videos and reads file identifiers, names, sizes, checksums, folder membership, sharing status and review links to verify those transfers. It is not designed to browse unrelated documents.

Storage and retention

OAuth credentials and tokens are stored in a restricted local configuration outside the production project's OneDrive directory. Local workflow records retain asset hashes, file identifiers, review links, approval records and technical results. Local media and records remain until the owner removes them.

Temporary Drive copies are deleted by exact file identifier after explicit approval. If a check or deletion fails, the workflow stops and preserves its record for investigation; a cloud copy may remain until the owner resolves the failure.

Services and disclosure

Google Drive stores the selected review copies. Pushover receives notification text and review links to deliver updates to the owner. A private link does not itself change Drive sharing permissions. When the owner requests Codex assistance, relevant workflow context and review metadata may be processed through that service. Episode Production does not sell Google user data or use it for advertising.

This website

This static website contains no custom analytics, tracking scripts or account forms. GitHub Pages hosts it and may process access logs, including IP addresses, under GitHub's privacy statement. Production videos and OAuth credentials are not published here.

Control and questions

The owner can revoke Google access through Google Account connections, remove local authorization files, and delete cloud or local copies. Revoking authorization prevents future authorized operations but does not itself delete existing files.

Questions or corrections can be raised with the owner through the website repository's issue tracker. Do not post credentials, private videos or other sensitive information in a public issue.
